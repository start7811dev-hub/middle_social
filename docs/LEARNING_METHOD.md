# 학습 방법론 — "어려운 게 재미있는" 구조

## 문제 정의
- 사회 과목이 지루한 이유는 내용이 어려워서가 아니다. 결과를 미리 알려 주고 외우게 하기 때문이다.
- 반대로 게임이 재미있는 이유는 쉬워서가 아니다. 내가 먼저 판단하고 바로 결과를 확인하기 때문이다.
- 그래서 이 앱은 쉽게 만드는 대신 **학생이 먼저 판단하게 만든다.** 학습과학에서 효과가 검증된 '바람직한 어려움'(desirable difficulty)을 게임 규칙으로 바꾼 것이 핵심이다.

## 학습 1회의 흐름 (한 성취기준 = 15~20분)
| 단계 | 학생이 하는 일 | 근거 | 재미 요소 |
|---|---|---|---|
| 1. 예측 | 3D 랩을 보기 전에 결과를 고른다. 화면은 흐리게 잠겨 있다 | 예측 오류가 클수록 기억이 강해진다(생성 효과·예측 오류) | 내기 / 반전 |
| 2. 실험 | 지구본을 돌리고, 곡선을 끌고, 변수를 바꿔 본다 | 능동적 조작이 수동 시청보다 오래 남는다 | 장난감처럼 만지기 |
| 3. 확인 | 내 예측과 실제를 나란히 본다. 빗나간 것은 '빗나감'으로 표시된다 | 오류 직후 피드백 | "어, 왜?"의 순간 |
| 4. 확신 베팅 | 문제마다 답을 고른 뒤 '찍었다 / 반반 / 확실'을 건다 | 확신했는데 틀린 오답이 가장 잘 고쳐진다(과잉확신 수정 효과) | 착각 발견 |
| 5. 현장 미션 | 생활 속에서 개념을 찾아 사진으로 남긴다 | 교과 개념을 내 생활에 연결(정교화) | 수집 |
| 6. 간격 복습 | 틀린 문제·찍어서 맞힌 문제가 1→3→7→14→30일 간격으로 돌아온다 | 간격 반복, 인출 연습 | 상자 올리기, 졸업 |

## 구현된 메커닉
1. **예측 게이트** — `lesson.predict`가 있으면 3D 스테이지가 흐리게 잠기고 질문 카드가 뜬다. 답을 고르면 열리고, 결과 카드에 내 예측과 정답·설명이 남는다.
2. **확신도 베팅** — 답을 고르면 확신도를 골라야 정답이 공개된다.
   - 확실 + 오답 = **착각 카드**. 오늘 복습에 바로 올라가고 우선 출제된다.
   - 찍었다 + 정답 = 운으로 맞힌 것으로 보고 복습 카드에 넣는다.
   - 홈의 '확실 답 적중률'은 내가 아는 것과 안다고 착각하는 것의 차이를 보여 준다.
3. **오늘의 복습** — 라이트너 상자 5단계. 맞히면 다음 상자로 가고 간격이 늘어난다. 틀리면 1번 상자로 돌아간다. 5번 상자를 통과하면 졸업한다.
4. **밝힌 세계** — 지리 단원을 끝낸 만큼 지구본의 해당 지역 도트가 단원 색으로 물든다. 진도율 숫자 대신 세계 지도가 채워진다.
5. **현장 미션** — `lesson.mission`이 있는 학습에 촬영 과제가 붙는다. iPad에서는 바로 카메라가 열린다.

## 콘텐츠 작성 규칙 (학습 1개당)
- **예측 질문 1개**: 학생 대부분이 직관으로 틀릴 만한 질문이 좋다. 예) "런던은 서울보다 북쪽인데 1월에 더 따뜻할까?"
- **복습 문제 5~8개**: 오답 선택지는 실제로 학생들이 자주 하는 오개념으로 만든다. 단순히 틀린 문장을 늘어놓지 않는다.
- **현장 미션 1개**: 집·학교·동네에서 15분 안에 할 수 있는 촬영 과제.
- **해설**: 정답의 이유와, 오답을 고른 학생이 무엇을 헷갈렸는지 한 문장씩.
