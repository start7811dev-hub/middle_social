# 쏘 대화 안전 설계

대상이 중학생이므로 **사회 학습 외의 대화는 하지 않고, 위험 신호에는 상담 대신 도움 받을 곳을 안내**하는 것을 원칙으로 한다.

## 처리 단계 (`shared/guard.ts`, `shared/pipeline.ts`)
| 단계 | 하는 일 | 모델 호출 |
|---|---|---|
| 1. 입력 정리 | 300자 제한, 최근 14턴만, user/assistant 외 역할 제거 | 없음 |
| 2. 키워드 사전 필터 | 위기(자해·자살·학대·폭력 피해), 연애·성, 다이어트, 의료·상담, 약물, 폭력 방법, 욕설·혐오, 개인정보(전화번호 등), 규칙 변경 시도 | 없음 |
| 3. 주제 분류 | Haiku가 study / offtopic / sensitive / crisis / pii / injection 중 하나로 판정. 애매하면 offtopic, 위기 신호가 조금이라도 있으면 crisis | Haiku |
| 4. 본 응답 | 쏘 시스템 프롬프트(절대 규칙 + 말투 + 현재 학습 문맥) | Sonnet |
| 5. 출력 검사 | 링크, 유해 표현, 규칙 노출이 섞이면 버리고 학습 전환 문구로 대체 | 없음 |

- 분류에서 study가 아니면 본 응답 모델을 **부르지 않는다**. 학습 외 대화가 모델까지 가지 않는다.
- 학습 문맥은 클라이언트가 보낸 글이 아니라 서버가 자기 콘텐츠 파일에서 읽는다(문맥 위조 방지).
- 분류기가 실패하면 본 응답을 부르지 않고 오류로 끝낸다(실패 시 닫힘).

## 응답 방식
- **학습 외(offtopic)**: "나는 사회 공부 담당이야" + 지금 학습의 개념 하나로 질문을 돌려준다.
- **민감(sensitive)**: 설명·조언 없이 거절하고, 부모님·선생님께 여쭤보라고 한 뒤 학습으로 전환.
- **위기(crisis)**: 상담하지 않는다. 믿을 수 있는 어른에게 말하라고 하고 청소년상담 1388, 자살예방상담 109, 112·119를 안내한다. 화면에는 바로 누를 수 있는 번호 카드가 뜨고, 말로 공부하기 중이면 자동 듣기를 멈춘다.
  - 요청서에는 "상담 대응 안 함"이 있었으나, 아이가 위험 신호를 보냈을 때 아무 반응 없이 학습으로 돌리는 것은 안전하지 않다고 판단해 **도움 받을 곳 안내만** 하도록 했다. 상담은 하지 않는다.
- **개인정보(pii)**: 적지 말라고 알려 주고 전환.
- **규칙 변경 시도(injection)**: 역할을 바꾸지 않고 전환.
- 정치: 현재 논쟁·정당·정치인에 대한 의견을 말하지 않고, 제도 원리와 서로 다른 관점의 근거만 설명한다.

## 말투
기분 나쁘지 않은 반말. 비꼬기·무시·명령조 금지. 틀린 답에는 잘한 부분부터 짚는다(`SSO_VOICE`).

## 개인정보
- 대화 내용은 서버에 저장하지 않고 로그에도 남기지 않는다. 앱에서도 패널을 닫으면 사라진다.
- 음성은 브라우저의 음성 인식이 글자로 바꾸고, 쏘 서버에는 글자만 간다. Safari·Chrome의 음성 인식은 Apple·Google 서버에서 처리될 수 있으므로, 학교 배포 시 이 점을 안내하거나 음성 입력을 끄고 글자 입력만 쓰게 할 수 있다.
- 학생 이름·학교 등을 묻지 않는다.

## 시험
- `npm test` — 사전 필터(잡아야 할 표현 17개, 교과 내용인데 걸리면 안 되는 표현 15개: 파키스탄·대공황·대마도·소주제 등), 출력 검사, 서버 흐름(위기 시 모델 미호출, 분류 실패 시 차단, 접근 코드, 요청 한도, 경로 조작 방지, CORS) 등 71개. 배포 빌드에 포함되어 실패하면 배포되지 않는다.
- `npm run redteam -- <주소>` — 실제 Claude로 32개 시나리오 점검(우회 시도, 역할극, 정치 의견 요구, 위기 표현 포함). 배포 후 매번 실행을 권한다.

## 한계 (운영 전에 알아 둘 것)
- 어떤 필터도 완벽하지 않다. 새로운 은어·우회 표현은 키워드에 없을 수 있고, 그 경우 분류 모델에 의존한다.
- 정확성: 쏘의 설명은 틀릴 수 있다. 프롬프트는 확실하지 않으면 교과서·선생님 확인을 권하게 되어 있다.
- 학교 배포 전에 교사가 레드팀 결과와 실제 대화 몇 건을 직접 확인하는 것을 권한다.
- 만 14세 미만 이용 시 보호자 동의 등 개인정보 관련 법적 검토는 별도로 필요하다(대화 저장은 하지 않지만 음성 인식은 OS·브라우저 제공자의 정책을 따른다).
