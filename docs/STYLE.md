# 스타일 정의 v0.1

토큰 원본: `src/styles/tokens.css`. 이 문서는 그 값의 의도와 사용 규칙을 정리한다.

## 1. 방향
- 레퍼런스: 라벤더 화이트 데이터 대시보드 + 엠보싱된 흰 지구본 + 헥스 도트 세계지도 + 떠 있는 핀 태그.
- 원칙 ① 화면의 주인공은 3D 장면이다. UI는 흰 카드와 얇은 선으로 물러난다.
- 원칙 ② 색은 정보를 구분할 때만 쓴다. 6개 액센트가 단원·핀·타일·차트에서 같은 의미로 반복된다.
- 원칙 ③ 숫자는 크게, 라벨은 작게. 학습 현황은 대시보드처럼 읽힌다.

## 2. 컬러
| 역할 | 토큰 | 값 |
|---|---|---|
| 배경 | `--bg` / `--bg-2` | #EEEDF7 / #F6F5FC |
| 표면(카드) | `--surface` | #FFFFFF |
| 선 | `--line` / `--line-2` | #E4E2F2 / #D6D3EA |
| 텍스트 | `--ink` / `--ink-2` / `--ink-3` | #2A2850 / #6B6990 / #A3A1C2 |
| 메인 | `--primary` | #6A5AE0 |
| 액센트 | `--sky` `--magenta` `--orange` `--green` `--coral` | #5DB8F2 #C25BD8 #F2995A #4FBF7A #E8697A |

- 단원마다 액센트 1개를 지정한다(`accent` 필드). 지구본 핀, 아이콘 타일, 진도 바, 캡슐이 이 색을 따른다.
- 정답·오답은 `--ok`(green), `--bad`(coral)만 쓴다.
- 다크 모드 토큰이 함께 정의되어 있다(`prefers-color-scheme`, `data-theme`).

## 3. 타이포그래피 — Pretendard 단일
| 레벨 | 크기/행간/굵기 | 용도 |
|---|---|---|
| Display | 56 / 1.05 / 600 | 핵심 수치 |
| H1 | 32 / 1.25 / 700 | 페이지 제목 |
| H2 | 24 / 1.30 / 700 | 섹션·교과서 제목 |
| H3 | 20 / 1.40 / 600 | 랩 제목, 큰 카드 제목 |
| H4 | 17 / 1.45 / 600 | 카드 제목, 문제 지문 |
| H5 | 15 / 1.50 / 600 | 리스트·패널 제목 |
| Body L | 17 / 1.70 / 400 | 성취기준 원문 |
| Body | 15 / 1.60 / 400 | 기본 본문 |
| Caption | 13 / 1.50 / 400 | 보조 설명 |
| Overline | 11 / 1.40 / 600, +0.08em | 라벨, 코드 |

- `h1~h5` 요소와 `.t-h1~.t-h5`, `.t-body-l`, `.t-caption`, `.t-overline` 클래스로 적용한다.
- 숫자는 `.num`(tabular figures)로 자릿수를 맞춘다.
- 한국어 줄바꿈은 `word-break: keep-all`.

## 4. 형태·깊이
- 라운드: 8 / 12 / 16 / 22 / 28 / pill. 카드 22, 3D 스테이지 28, 버튼·칩 pill.
- 그림자: 보라빛이 섞인 낮고 넓은 그림자 2단계(`--sh-1` 기본 카드, `--sh-2` hover). 핀은 `--sh-pin`.
- 간격: 4 기반(4·8·12·16·24·32·48).

## 5. 컴포넌트
- **아이콘 타일**: 48px 라운드 사각, 액센트 그라디언트 + 흰 라인 아이콘. 소 30 / 대 60.
- **핀 태그**: 흰 카드 + 작은 타일 + 2줄 텍스트(교과·번호 / 단원명) + 꼬리. 지구본 뒤로 가면 서서히 숨는다.
- **캡슐**: 일반사회 단원 선택용 세로 알약. 선택되면 액센트 그라디언트로 채워지고 커진다. 한 번 더 누르면 열린다.
- **링 차트**: 정답률·진도율. 4px 선.
- **진도 바**: 5px, 액센트 그라디언트.

## 6. 아이콘
- Lucide 라인 아이콘 세트(ISC 라이선스). 선 1.6px, 라운드 캡.
- 이름 매핑은 `src/components/Icon.tsx` 한 곳에서 관리하고, 콘텐츠 JSON은 매핑 이름(`globe`, `temple` 등)만 쓴다.

## 7. 로고
- 안경 쓴 캐릭터 스케치를 벡터 라인 드로잉으로 옮긴 마크. `src/components/Logo.tsx`.
- 작게 쓸수록 선을 굵게 한다(28px 이하 5.2, 48px 이하 4.4, 그 이상 3.6 / 100 그리드 기준).
- 렌즈는 표면색으로 채워 배경 위에서도 눈이 또렷하게 보이게 한다.
- 앱 아이콘: `build/icon.svg` → `build/icon.png`(1024).

## 8. 3D 장면
- 지구본: 매트한 연라벤더 구체(`--globe-base`) 위에 육지를 얕은 육각 기둥으로 돌출해서 엠보싱 질감을 낸다.
- 조명: 밝은 반구광 + 좌상단 키라이트 + 우하단 필라이트. 어두운 면이 생기지 않게 한다.
- 강조: 학습 지역의 도트만 단원 액센트로 물들인다. 네트워크는 하늘색→마젠타 그라디언트 아크.
- 조작: 드래그 회전, 핀치 확대(iPad), 핀 탭으로 단원 이동.
