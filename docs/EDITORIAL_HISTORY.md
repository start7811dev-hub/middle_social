# 역사·근현대사 콘텐츠 편집 원칙

역사 단원(역사①·②)과 사회 단원의 근현대사 관련 서술에 적용한다.
원칙은 '어느 진영의 시각'이 아니라 **검증 가능한 기준**으로 정한다. 학교·학부모에게 설명할 수 있어야 하기 때문이다.

## 1. 서술 기준 (우선순위 순)
1. 대한민국 헌법 전문 — "3·1운동으로 건립된 대한민국임시정부의 법통"을 계승한다는 헌법의 역사 인식
2. 교육부 고시 교육과정의 성취기준과 내용 요소
3. 학계 통설과 공인 사료 — 국사편찬위원회, 동북아역사재단 등 공공 연구기관 자료와 1차 사료
4. 사료로 확인되지 않는 해석은 '해석'으로 표시한다

## 2. 배제하는 서술
**식민사관 논리** — 학계에서 근거가 없다고 정리된 주장은 사실처럼 서술하지 않는다.
- 정체성론(한국사는 발전 없이 정체되었다), 타율성론(외세에 의해서만 움직였다), 당파성론(분열이 민족성이다)
- 임나일본부설 등 고대사 왜곡
- 이런 주장은 '식민사관이 왜 만들어졌고 어떻게 반박되었는가'를 배우는 비판 학습의 대상으로만 다룬다.

**일제 강점기를 시혜로 보는 틀**
- 철도·공장·통계 수치 같은 개발 지표는 '누구를 위해, 무엇을 가져가기 위한 개발이었나'라는 수탈 구조의 맥락 없이 쓰지 않는다.
- 국권 피탈 과정의 강제성, 토지·식량·자원 수탈, 강제 동원, 일본군'위안부' 피해, 민족 말살 정책은 사료와 함께 명시한다.
- 독립운동(3·1운동, 대한민국임시정부, 무장 독립 투쟁, 실력 양성 운동 등)을 강점기 서술의 주어로 둔다.

**영토·명칭**
- 독도는 대한민국 고유 영토로 서술하고, 역사·국제법적 근거 사료를 함께 제시한다.
- '동해' 표기. '일본해'는 쓰지 않는다(지도 이미지 포함).

## 3. 용어 기준
| 쓰지 않음 | 사용 |
|---|---|
| 한일합방, 한일병합(중립 서술처럼 단독 사용) | 국권 피탈, 한국 병합 조약의 강제 체결 |
| 일제 시대, 식민지 시대(단독) | 일제 강점기 |
| 위안부(단독), 종군위안부 | 일본군'위안부' 피해자 |
| 징용 노동자(자발적 뉘앙스) | 강제 동원 피해자 |
| 일본해 | 동해 |
| 조선 진출, 대륙 진출(일본의 침략 행위에 대해) | 침략 |

`npm run validate`가 콘텐츠에서 이 용어를 찾아 경고한다(`scripts/validate-content.mjs`의 TERM_RULES).

## 4. 학계에서 실제로 논쟁 중인 해석
근거가 갈리는 현대사 쟁점(인물 평가, 일부 사건의 성격 등)은 한쪽 결론을 정답으로 주지 않는다.
- 교육과정 문구를 기본으로 따른다.
- 서로 다른 해석을 각각의 사료 근거와 함께 제시하고, 학생이 사료를 읽고 판단하게 한다.
- 이 경우 복습 문제는 '어느 해석이 옳은가'가 아니라 '이 해석의 근거 사료는 무엇인가'를 묻는다.
- 위 2장에서 배제한 주장은 이 '논쟁' 범주에 넣지 않는다.

## 5. 검수 절차
- 역사·근현대사 학습에는 `sources`(출처 목록)를 반드시 단다.
- 원고 → 역사 전공 검수자 1인 → 교사 검수 1인을 거친 뒤 `standard.verified`와 함께 배포한다.
- 외부 콘텐츠 소스(CONTENT_GUIDE.md)로 들어오는 역사 콘텐츠도 같은 검증을 통과해야 한다.
